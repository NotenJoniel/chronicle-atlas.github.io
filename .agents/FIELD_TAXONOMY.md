# 人物の分野タグ（`characters[].field`）— 判断基準ログ

> このドキュメントは、`characters[].field`（機能7分類＋`other`）を全9タイムライン393人に付与した際の判断根拠を記録したものです。
> 「なぜアルキビアデスが`governance`なのか」のような疑問に、同じ結論へ再到達できるようにするための参照資料です（Opus 5とのすり合わせにより導入）。
> 個々のレコードにはコメントを残さず、ここに集約しています（JSON側にコメント欄が無いため）。

---

## 1. 分類の定義

社会における**機能**で分類する（具体的職業名ではない）。全時代・全文明で対応者が見つかることを条件に選定した7分類＋、機能を持たない人物のための逃げ道ではない受け皿として`other`の計8分類。

| ID | 表示名 | 定義 |
|---|---|---|
| `governance` | 統治 | 意思決定の頂点にいる人。王・皇帝・執政官・大名・君主・摂政・女王など |
| `military` | 軍事 | 軍を率いる／軍事戦略を担うことが本分の人。統治者と重なる場合は`governance`を優先 |
| `administration` | 行政・法 | 制度を作り運用する人。立法者・丞相・行政官・外交官・改革者 |
| `thought` | 思想・信仰 | 世界の説明を担う人。哲学者・宗教指導者。哲学と宗教は未分化なため統合 |
| `scholarship` | 学術・技術 | 知識を体系化し、ものを作る人。歴史家・科学者・発明家・探検家 |
| `arts` | 芸術 | 表現を作る人。詩人・劇作家・彫刻家・茶人 |
| `commerce` | 経済・交易 | 富の流れを担う人。商人・金融家 |
| `other` | その他 | **公的機能を持たず、物語的文脈でのみ記録されている人物に限る**（§2-4参照） |

## 2. 運用ルール

1. **1人1タグ**。複数の機能を兼ねていても、最も知られている機能を1つ選ぶ
2. **`governance`／`military`／`administration`の間で迷ったら`governance`を優先**（このルールは統治者クラスタ内でのみ適用し、`thought`/`arts`/`scholarship`との迷いには機械的に適用しない — 政治との関わりを理由に全員`governance`に寄せると、これらのカテゴリが実質機能しなくなるため）
3. **キーは英語**（`governance`等）、表示名は日本語
4. **`other`は逃げ道にしない。** 判断に迷ったという理由だけで`other`を選んではならない（迷った場合はルール2の通り`governance`優先）。`other`が許されるのは、**公的な役職・機能を一切持たず、悲恋・忠義などの物語的文脈でのみ記録されている人物**だけである。判断基準：「この人物の`role`欄から統治・軍事・行政・思想・学術・芸術・経済のいずれかの実質的な機能を一つでも取り出せるか？」に**No**と答えられる場合のみ`other`
5. **独立した思想的著作を残している場合、公職の有無にかかわらず`thought`を優先する**（キケロ・セネカの例。ルール2の`governance`優先よりもこちらが勝つ、明示的な例外規定）

## 3. 繰り返し適用したパターン

実データを通して、以下のパターンが再現可能な判断として機能した。

| パターン | 判定 | 理由 |
|---|---|---|
| 「軍師」単独、または「軍師/武将」 | `military` | 戦役単位の軍事戦略立案は軍事機能とみなす |
| 「軍師」に「政治家」「丞相」等の統治職が併記される（諸葛亮、司馬懿、陸遜など） | `administration` | 国家運営の実権を担った期間の方が持続的な機能と判断 |
| 「群雄」単独（統治領域を持つ独立勢力） | `governance` | 事実上の領主・王として扱う |
| 「武将/群雄」（武将が先に来る） | `military` | 戦闘者としての側面が主 |
| ローマ「独裁官」 | `governance`（原則） | 非常時とはいえ国家の全権を握る官職 |
| ただし独裁官でも、特定の**戦術・戦法**そのものが歴史的意義の中心（例：ファビウス・マクシムスの遅滞戦術） | `military` | 統治より軍事ドクトリンとしての功績が支配的 |
| 反乱指導者で、恒久的な統治確立に至らなかった者（陳勝・呉広、スパルタクス、ユダ・マカバイ等） | `military` | 武装蜂起の組織化が主機能。恒久国家樹立に至った場合（例：ハスモン朝独立を達成したシモン）は`governance` |
| 独立した哲学的著作を残した人物が政治家も兼ねる（キケロ、セネカ） | `thought` | 政治的言論のみで著作を残さない弁論家（デモステネス）とは区別。政治関与を理由に一律`governance`にはしない |
| 政治的枠組みの中で語られるストア派信奉者（小カトー） | `governance` | 独立した哲学著作を残していない点でキケロ・セネカと区別 |
| 外交官・説客 | `administration` | 古代に専業外交官はほぼ存在しないため、外交は行政機能に含める |
| 探検家（張騫） | `scholarship` | 「未知の地の発見・報告」という知的貢献を重視し、単なる使者（`administration`）とは区別 |

## 4. 個別の難しい判断（フェーズA・Bで実際に迷ったもの）

### 4-1. 古代ギリシア（フェーズA、26人中6人で判断に実質的な迷いが生じた）

| 人物 | 迷った理由 | 決定 | 決め手 |
|---|---|---|---|
| ソロン | 立法者／統治者／詩人 | `administration` | 「制度設計者」であり恒久的な統治者ではない |
| クレイステネス | 改革者、統治者とも取れる | `administration` | ソロンと同型の制度設計者 |
| テミストクレス | 政治家／将軍／行政（艦隊建造） | `governance` | ルール2適用 |
| アリステイデス | 政治家／行政（貢租査定） | `governance` | 役職表記「政治家」を優先 |
| アルキビアデス | 統治者／将軍／寝返り | `governance` | ルール2適用 |
| デモステネス | 弁論家（芸術？）／政治家 | `governance` | 弁論はアテナイ民主政における政治活動そのものであり、独立した著作（哲学等）は残していない |

Opus 5の追記コメント: 「6件全件が決定に至り、決め手が言語化できている＝分類が機能している証拠。迷いがゼロにならないのは実態を反映した正常な結果であり、フェーズBに進む妨げにはならない」

| 小カトー（共和政ローマ） | 政治家・ストア派哲学者 | `governance` | ストア派への傾倒は生き方・信条であり、キケロのような独立した哲学著作は残していない |

### 4-3. 中国系（戦国・楚漢・三国・漢王朝）

### 4-4. 「機能」を持たない人物 → `other`

以下は7分類（`governance`〜`commerce`）のいずれにも本質的に馴染まない。公的な役職・機能を持たず、悲恋・忠義などの物語を通じて記憶されている人物である。

- 虞姫（楚漢戦争、項羽の愛妾。詩を残したという伝承はあるが、記憶されているのは垓下での自刎そのもの）
- 貂蝉（三国志、`faction`も`other` — 『三国志演義』の創作人物であり、史実の人物ですらない）
- お市の方（日本の戦国時代、信長の妹）
- 淀殿（日本の戦国時代、秀吉の側室）

**当初はこの4人を`arts`（文化的記憶の中で生き続ける存在という意味での近似値）に寄せていたが、Opus 5の指摘により`other`に付け替えた。** 理由：`arts`は「表現を作る人」という定義であり、この4人はそこに当てはまらない。無理に`arts`に入れると、分野別に並べたときに蔡邕・王羲之・千利休・狩野永徳のような本物の表現者と同列に並んでしまい、`arts`というカテゴリの定義自体が濁る。正しく分類できないものを無理に押し込めた結果、正しく分類できていた他の`arts`該当者側が汚れる、という実害があった。

`other`は「分類の敗北」ではなく、**7分類が公的機能を前提に設計されていることを、データ側でも明示する受け皿**として機能する。ドキュメントに但し書きを書くだけでは実装との乖離が生じるため、データ（enum）側にも対応する値を持たせた。

将来もし「王侯の配偶者・血縁」のような属性が増えるようであれば、9つ目の分野追加ではなく、既存の「人物と属性は別軸にすべき」という設計方針（Opus 5の指摘）に従い、別フィールドの検討対象とする。

## 5. 観測されたデータの偏り（分類の欠陥ではなく実態の反映）

- **ヘレニズム世界**は29人中23人が`governance`。ディアドコイ戦争＝後継者の王位継承争いという題材そのものが「王のクロニクル」であるため、偏りは正常
- **日本の戦国時代**は46人中`commerce`・`scholarship`が0人。今井宗久のような商人や南蛮渡来の技術者はまだ`characters[]`に存在しないため（Opus 5の議論で候補として名前が挙がったのみ、追加はしていない）
- どの時代でも`military`と`governance`が多数を占め、`commerce`が最も希少という傾向は共通。これはOpus 5の指摘通り「経済史は出来事側に現れ、名前の残る個人としては現れにくい」という古代・中世共通の史料的制約を反映している

## 6. UI実装時の申し送り（未実装）

`field`は現時点（フェーズB完了時点）で**データ層のみ**に存在し、`shared/timeline-core.js`はまだ一切参照していない（サイドバー・フィルタ・人物モーダルのどこにも表示されない）。将来UIに反映する際は、以下を守ること。

- サイドバーを分野別にグルーピングする場合、**`other`は最後尾に固定**する
- 分野で絞り込むフィルタUIを作る場合、**`other`は選択肢に含めない**（「その他で絞り込む」という操作自体に意味がないため）
- 人物詳細カードに分野を表示する場合、`field === 'other'`のときは**分野の行そのものを非表示**にする（「その他」と表示するより、何も表示しない方が自然）
